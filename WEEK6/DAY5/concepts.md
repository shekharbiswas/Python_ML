# Week 6 - Day 5: Presenting the Project

## Day Goal
Today you present. The slides are drafted and the project is frozen. There is no coding today. Spend the time before the presentation rehearsing and preparing for questions.

**Presentation: today at 2:30 pm.**

**Key theme for today:** *"Be clear about what you built, what you chose, and why, and be honest about the limits."*

---

## Concept 1: Showing the Pipeline Carefully
A full run can take a long time, and live runs fail at the worst moments.

- Do not run the entire pipeline live
- Show the folder structure, the one command (`python run_pipeline.py`), and a screenshot of the log from a successful run
- If you demo anything live, keep it short, such as loading the saved model and predicting a few rows with `predict.py`
- Keep backups: screenshots of every result and the PDF copy of the slides

---

## Concept 2: Questions to Be Ready For
1. Why did you use MAE?
2. Did your model beat the simple baseline?
3. How do you know there was no data leakage?
4. Why did you split by time and not randomly?
5. What happens if a new month of data has a different schema?
6. What would you do first with more time?
7. Which parts of this pipeline will you reuse for your next project?

Prepare one line for each. If you do not know something, say so plainly and say how you would find out.

---

## Concept 3: Delivery Tips
- Start with the question, not with the tools
- Spend the most time on the pipeline diagram and the results slide
- Say the baseline number every time you say the model number
- Keep to the time, and cut content if you run over
- Speak about the choices with "because"

---

## Key Takeaways
1. Do not demo the full pipeline live
2. Prepare one line for each likely question
3. Be honest about limits
4. Keep to time
