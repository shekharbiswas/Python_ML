## Task 1: Build the Slides (90 min)
Use the 6-7 slide structure from the Concepts file. Pull content from your project files, not from memory:

| Slide | Take it from |
|---|---|
| Question | `decision_log.md` |
| Data | `config.yaml`, `data_audit.csv` |
| Pipeline | your README (turn it into a diagram) |
| Data quality | `cleaning_report.csv` |
| Results | `model_comparison.csv`, `test_results.csv` |
| Where it fails | `error_breakdown.csv` |
| Limits and next steps | `decision_log.md`, README |

**Check:** each slide has one main message that fits in a sentence, and no slide has code on it.

---

## Task 2: Prepare the Visuals and Backups (45 min)
1. Make **one clear chart** for the results (baseline vs. model, validation and test) and **one chart** for where the model fails (for example, MAE by hour of day)
2. Take a **screenshot of the pipeline log** from a successful `--stage all` run
3. Save a PDF copy of your slides as a backup

**Check:** if your laptop failed, could you still present from the PDF alone?

---

## Task 3: Rehearse and Prepare for Questions (75 min)
1. Rehearse the full presentation **out loud, with a timer**, at least twice. Cut content if you run over
2. Write a one-line answer to each question in the Concepts file
3. Decide who says what, if you are presenting as a group

**Check:** you can explain the whole project in two minutes without looking at the slides.

---

## Deliverables by End of Day 5
1. Finished slides, plus a PDF backup
2. Two charts and one log screenshot
3. Written one-line answers to the likely questions
4. The presentation, delivered at 15:30

---

## Self-Check Questions

2. Where does your model beat the baseline, and where doesn't it?
3. Which three decisions would you defend first if challenged?
4. Which parts of this pipeline will you reuse for your own project next week?
